# schema-coexistence-spec

A vocabulary anchor for the **core / edge schema separation** model.

- **Core schema** holds stable judgment. Updated only via explicit calibration.
- **Edge schema** holds evolving capability. Can self-improve, mutate, be discarded.
- New skills mature in edge before being **promoted to core with provenance**.

This separation is what allows aggressive self-evolution at the edge without contaminating stable judgment at the core.

This name refers to a position outlined in detail at:

- [coevolution-kernel](https://github.com/hegu-1/coevolution-kernel) — main thesis
- [claude-cognition-skills](https://github.com/hegu-1/claude-cognition-skills) — reference implementation

This repository is a vocabulary anchor; the substantive content is in the linked thesis and implementation.
